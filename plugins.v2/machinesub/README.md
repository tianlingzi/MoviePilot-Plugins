# 机器字幕生成与翻译 (MachineSub)

使用 faster-whisper 自动生成视频字幕，并支持百度翻译、火山引擎翻译将英文字幕等翻译成中文。

## 主要功能

- **字幕生成**：支持从视频音轨、内嵌字幕或外挂字幕生成字幕
  - 使用 faster-whisper 进行语音识别（ASR）
  - 支持优先使用外挂字幕或内嵌字幕，减少 ASR 耗时
  - 支持字幕源语言偏好（仅英文 / 英文优先 / 原音优先）
  - 支持自动检测语言
- **机器翻译**：支持将外语字幕翻译成中文
  - 百度翻译
  - 火山引擎翻译
  - 支持批量翻译，提升翻译效率
  - 支持双语字幕输出（中文 + 原文）
  - 支持英文整句合并
- **强制翻译**：忽略已有字幕检查，直接对视频进行处理
  - 仅在「手动执行一次」打开时可用
  - 启用后跳过目标字幕存在性检查，直接执行音频提取、字幕生成和翻译
  - 适用于需要重新生成或覆盖已有字幕的场景
- **任务管理**：支持任务队列机制与任务状态列表展示
  - 等待中 / 处理中 / 已完成 / 已忽略 / 失败
  - 支持媒体入库自动执行
  - 支持手动执行一次

## 字幕生成流程

1. 获取视频元数据，确定音轨和字幕语言偏好
2. 按优先级查找可用字幕源：
   - 外挂字幕（符合语言偏好）
   - 内嵌字幕（符合语言偏好，需提取）
   - 音轨 ASR 识别（faster-whisper）
3. 如启用翻译，将生成的字幕通过机器翻译翻译成中文
4. 输出双语字幕文件（`.zh.机翻.srt`）

## 强制翻译说明

正常情况下，插件会检查视频是否已有目标字幕（外挂或内嵌），如已存在则跳过处理（标记为「已忽略」）。

启用「强制翻译」后，插件将：

- 跳过 `__target_subtitle_exists` 检查
- 直接对视频执行音频提取、字幕生成和翻译
- 任务列表中来源会标记「（强制）」

**使用场景**：已有字幕质量不佳或需要重新生成时使用。

## 配置说明

| 配置项 | 说明 | 默认值 |
|------|------|------|
| 启用插件 | 是否启用插件 | 否 |
| 清理历史记录 | 清除已完成的任务记录 | 否 |
| 发送通知 | 是否发送任务执行通知 | 否 |
| 媒体入库自动执行 | 监听到媒体入库事件后自动执行字幕生成 | 是 |
| 手动执行一次 | 手动触发一次字幕生成任务 | 否 |
| 强制翻译 | 忽略已有字幕检查，直接处理（仅手动执行时可用） | 否 |
| 触发字幕生成的视频文件不小于(MB) | 小于此大小的视频不处理 | 10 |
| 字幕源语言偏好 | 多语言字幕/音轨时的优先选择 | 英文优先 |
| 翻译成中文 | 是否使用机器翻译将字幕翻译成中文 | 否 |
| 允许从音轨生成字幕 | 是否允许从视频音轨中提取字幕 | 是 |
| 自动检测语言 | 使用 whisper 模型自动检测语言 | 否 |
| faster-whisper模型 | 语音识别模型选择 | base |
| 使用代理下载模型 | 需配置 MP 环境变量 PROXY_HOST | 是 |
| 翻译服务 | 百度翻译 / 火山引擎翻译 | 百度翻译 |
| 启用批量翻译 | 是否启用批量翻译 | 是 |
| 每批翻译行数 | 批量翻译的每批行数 | 10 |
| 上下文窗口大小 | 翻译上下文窗口（机器翻译建议设为0） | 0 |
| 翻译请求重试次数 | 翻译失败时的重试次数 | 3 |
| 翻译英文时合并整句 | 是否合并英文字幕整句 | 否 |

## 翻译服务配置

### 百度翻译

1. 前往 [百度翻译开放平台](https://fanyi-api.baidu.com) 注册并开通通用翻译服务
2. 获取 APP ID 和密钥
3. 在插件配置中填入

### 火山引擎翻译

1. 前往 [火山引擎控制台](https://www.volcengine.com/docs/4640/65067) 开通机器翻译服务
2. 获取 Access Key 和 Secret Key
3. 在插件配置中填入

## 依赖

- `faster-whisper`：语音识别
- `iso639`：语言代码处理
- `srt`：字幕文件解析与生成
- `requests`：机器翻译 API 调用（MoviePilot 已内置）
- `psutil`：CPU 核心数获取（MoviePilot 已内置）
- `lxml`：HTML 标签解析（MoviePilot 已内置）
- 容器内需可用 `ffmpeg` / `ffprobe`

## 字幕文件命名

- 原始语言字幕：`{视频文件名}.{语言代码}.srt`（如 `movie.en.srt`）
- 中文翻译字幕：`{视频文件名}.zh.机翻.srt`（双语字幕，中文在上原文在下）
