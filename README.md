# MachineSub - 字幕生成与机器翻译

面向 MoviePilot V2 的字幕生成与机器翻译插件。

<br />

参考项目autosubV1-3

## 插件列表

| 插件        | 目录                      | 版本  | 主要功能                                      |
| --------- | ----------------------- | --- | ----------------------------------------- |
| 字幕生成与机器翻译 | `plugins.v2/machinesub` | 1.0 | faster-whisper 语音识别、字幕提取、百度/火山引擎机器翻译、强制翻译 |

## 功能概述

用于从视频音轨、内嵌字幕或外挂字幕生成字幕，并通过机器翻译（百度翻译 / 火山引擎翻译）将英文字幕等翻译成中文。

### 主要功能

- 支持 faster-whisper 语音识别，从音轨自动生成字幕。
- 支持优先使用外挂字幕或内嵌字幕，减少 ASR 耗时。
- 支持百度翻译、火山引擎翻译将外语字幕翻译成中文。
- 支持双语字幕输出（中文 + 原文）。
- 支持批量翻译，提升翻译效率。
- 支持字幕源语言偏好（仅英文 / 英文优先 / 原音优先）。
- 支持监听媒体入库事件自动执行字幕生成。
- 支持手动执行一次，并可选择**强制翻译**——忽略已有字幕检查，直接对视频进行音频提取、字幕生成和翻译。
- 支持任务队列机制与任务状态列表展示。

### 强制翻译

当「手动执行一次」选项打开时，可选择是否启用「强制翻译」。

- 启用后，插件将跳过「目标字幕是否已存在」的检查，直接对视频进行音频提取、字幕生成和翻译。
- 适用于需要重新生成或覆盖已有字幕的场景。

## 安装方式

在 MoviePilot 第三方插件仓库中添加本仓库地址，即可安装「机器字幕生成与翻译」插件。
